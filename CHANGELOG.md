# Changelog

Notable changes to Chippy are recorded here. The project uses semantic
versioning, with pre-1.0 minor releases allowed to change public APIs as the
design settles.

Chippy releases and The Markdown Works content-contract releases are versioned
independently. An annotated Git tag identifies the exact checked commit for each
Chippy release. Unreleased work accumulates under the heading below.

## Unreleased

## 0.2.0 — 2026-10-07

- Established the first tagged Chippy release baseline.
- Added request-time Markdown rendering with directory routes, nested layouts,
  reusable partials, collections, and colocated or global static assets.
- Added YAML frontmatter compatible with The Markdown Works content contract
  1.0.0, predefined social metadata, `noindex`, and a generated sitemap.
- Added the server-rendered contact demonstration, styled error pages, validated
  listener configuration, and production Fly.io packaging.
- Added the dark responsive demo site, portable content example, comprehensive
  test suite, developer documentation, and self-hosted Gleam code reference.
